# Магазин одежды — Контрольная работа №2

Учебный проект по дисциплине «Фронтенд и бэкенд разработка».

**Автор:** Бенях Даниил Николаевич  
**Группа:** ЭФБО-03-25

## Тематика проекта

Интернет-магазин одежды «Artel Studio».

Проект сохраняет тематику контрольной работы №1 (`kr1-html-css-shop`), но создаётся в отдельном репозитории с новой вёрсткой на Bootstrap.

## Цель работы

Разработать адаптивный интерфейс интернет-магазина одежды с использованием Bootstrap.

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных товаров;
- подвал страницы.

## Используемые технологии

## Запуск

Откройте `index.html` в браузере. Для загрузки Bootstrap 5.3.3 через CDN необходимо подключение к интернету.

## Текущий этап

Выполнена главная страница для практического занятия №9. Страницы `catalog.html`, `product.html` и `order.html` запланированы для следующих этапов; ссылки на них пока являются заготовками.

## Проверка адаптивности

Откройте режим мобильного устройства в DevTools и проверьте страницу на ширинах 375, 768 и 1200 px: раскрытие меню, перестроение колонок, отображение изображений и отсутствие горизонтальной прокрутки.
