# Магазин одежды — Контрольная работа №2

Учебный проект по дисциплине «Фронтенд и бэкенд разработка».

**Автор:** Бенях Даниил Николаевич  
**Группа:** ЭФБО-03-25

## Тематика проекта

Интернет-магазин одежды «Artel studio».

Проект сохраняет тематику контрольной работы №1 (`kr1-html-css-shop`), но создаётся в отдельном репозитории с новой вёрсткой на Bootstrap.

## Цель работы

Разработать адаптивный интерфейс интернет-магазина одежды с использованием Bootstrap.

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных товаров;
- подвал страницы.

- HTML;
