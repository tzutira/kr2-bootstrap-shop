# Магазин одежды — Контрольная работа №2

Учебный проект по дисциплине «Фронтенд и бэкенд разработка».

**Автор:** Бенях Даниил Николаевич  
**Группа:** ЭФБО-03-25

## Тематика проекта

Интернет-магазин одежды «Artel Studio». Проект сохраняет тематику КР №1
(`kr1-html-css-shop`), но использует отдельный репозиторий и вёрстку на Bootstrap.

## Практическая работа 9

Главная страница: шапка, адаптивная навигация, hero-блок, преимущества,
сетка шести популярных товаров и подвал. Для раскладки используются
`container`, `row`, `col-*`, отступы и другие utility-классы Bootstrap.

## Практическая работа 10

Тема: «Страница на Bootstrap: компоненты».

Выполнено:

- единая `navbar` на четырёх страницах, активный пункт, мобильное меню и `dropdown`;
- `catalog.html`: шесть карточек `card` с фотографиями, описаниями, ценами и `badge`;
- кнопки `btn-primary`, `btn-outline-primary`, `btn-secondary`, `btn-outline-secondary`;
- информационные сообщения `alert` и результат проверки формы `alert-success`;
- `product.html`: выбранный товар, изображение, описание, цена, `breadcrumb`
  и адаптивная таблица характеристик;
- `order.html`: форма с `form-control`, `form-select`, `input-group`, `form-check`,
  обязательными полями, проверкой e-mail и телефона, кнопкой очистки;
- `modal`: быстрая заявка для выбранного товара, имя, телефон и согласие;
- `accordion`: частые вопросы в каталоге;
- карточки популярных товаров на главной переведены на компонент `card`;
- Bootstrap CSS и JS Bundle 5.3.8 подключены на каждой странице;
- минимальные собственные стили для размеров изображений;
- небольшой JavaScript для выбора товара и демонстрационной обработки форм.

## Используемые технологии

HTML, Bootstrap 5.3.8, CSS, JavaScript, Git и GitHub. Сборка и установка npm-пакетов
не требуются. Данные каталога находятся в HTML и в массиве `products` файла
`js/shop.js`; при изменении ассортимента их нужно обновлять согласованно.

## Запуск

Откройте `index.html` в браузере. Для Bootstrap через CDN необходимо подключение
к интернету. JavaScript нужен для мобильного меню, dropdown, modal, accordion,
выбора товара и проверки учебных заявок.

Ссылки `product.html?product=1` … `product.html?product=6` открывают соответствующие
товары. Без параметра показываются джинсы Coated Noir. Неизвестный идентификатор
показывает сообщение «Товар не найден». Ссылка на заявку переносит выбранный товар
в `order.html?product=...`; кнопка «Очистить» сбрасывает форму, включая выбор товара.

## Учебные формы

Формы проверяют обязательные поля, формат e-mail, количество цифр телефона
и согласие. Полная форма принимает 10 цифр телефона после +7, быстрая — от 10 до 15
цифр с необязательным международным префиксом. После проверки появляется сообщение
о подготовленной учебной заявке. Изменение полей скрывает старое подтверждение.

Данные не отправляются на сервер, не сохраняются в браузере и не попадают в URL.
Без JavaScript кнопки отправки отключены. Backend, оплата, корзина и реальные
заказы не реализуются в рамках этой практики. Цены и характеристики демонстрационные.

## Проверка результата

1. Открыть каждую из четырёх страниц и проверить переходы и активный пункт меню.
2. Проверить ширины **375, 768, 1024 и 1440 px**: отсутствие горизонтальной
   прокрутки, читаемость формы, таблицы и модального окна.
3. Убедиться, что каталог содержит 1, 2 или 3 колонки в зависимости от ширины.
4. На узком экране раскрыть navbar; проверить меню «Дополнительно».
5. В каталоге открыть быструю заявку для разных товаров, проверить название,
   закрытие крестиком и Escape, обязательность полей и сообщение после заполнения.
6. Раскрыть и закрыть вопросы в accordion.
7. Проверить переходы всех шести товаров из каталога в описание и затем в заявку.
8. Попробовать пустую форму, неверный e-mail, неполный телефон и отсутствие согласия.
9. Заполнить корректные данные, увидеть учебное подтверждение, затем очистить форму.
10. Проверить неизвестный товар: `product.html?product=999`.

Проверено в Chrome: четыре страницы на всех четырёх ширинах, перестроение сетки,
navbar и dropdown, modal, accordion, переходы шести товаров, неизвестный товар,
валидация и очистка формы. Ошибок JavaScript не обнаружено.
